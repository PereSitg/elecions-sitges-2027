# Logotips dels Partits Polítics

Dins d'aquesta carpeta pots col·locar els logos dels partits en format **PNG** (preferiblement amb fons transparent). 

El nom de cada fitxer de logotip ha de coincidir amb el nom del partit normalitzat de la següent manera:
* ERC -> `erc.png`
* Junts -> `junts.png`
* PSC -> `psc.png`
* Fets per Sitges -> `fets-per-sitges.png`
* Solucions -> `solucions.png`
* PP -> `pp.png`
* Vox -> `vox.png`
* Guanyem -> `guanyem.png`
* Verds Comuns Sitges -> `verds-comuns-sitges.png`
* Aliança Catalana -> `alianca-catalana.png`
* SitgesGI -> `sitgesgi.png`

---

### Fallback Automàtic (Cercle de Color)
Si no poses cap fitxer a la carpeta o si el logo falla al carregar-se, la pàgina web ho detectarà de forma transparent i **mostrarà automàticament el cercle amb el color representatiu del partit** (així evitem imatges trencades o buits).
